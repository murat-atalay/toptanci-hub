# Fonts Directory

This directory should contain the following fonts for .NET MAUI:

- `OpenSans-Regular.ttf` - Default regular font
- `OpenSans-Semibold.ttf` - Default semibold font

## How to Add Fonts

1. Download the Open Sans font family from [Google Fonts](https://fonts.google.com/specimen/Open+Sans)
2. Place the `.ttf` files in this directory
3. The fonts will be automatically registered in `MauiProgram.cs`
